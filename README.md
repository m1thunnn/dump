# Simple Interest Calculator

A simple calculator that calculates the interest earned on a principal amount based on the interest rate and time period.

## Formula

Simple Interest (SI) is calculated using the formula:

**SI = (P × R × T) / 100**

Where:

- **P** = Principal amount
- **R** = Rate of interest per year (%)
- **T** = Time period in years

## Example

If:

- Principal = 10,000
- Rate = 5%
- Time = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100 = 1,000**

**Total Amount = Principal + Simple Interest = 11,000**

## Features

- Calculates simple interest quickly
- Easy to use
- Simple and beginner-friendly
- Suitable for learning basic programming concepts

## Usage

Enter the principal amount, rate of interest, and time period to calculate the simple interest and total amount.
